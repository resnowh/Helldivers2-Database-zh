## 目标与原则

本仓库整理《Helldivers 2》三大主阵营的敌人资料，重点覆盖：

- 中文名与英文名对照
- 弱点与处理思路
- 血量、部位生命值、装甲等级
- 武器、手雷、战略配备的伤害与实战定位

整理原则：

1. 先记录能被可靠交叉验证的数据，再标记待补项。
2. 中文译名优先采用游戏内中文、官方中文和中文 Wiki；没有统一结论时保留英文名或注明常用译名。
3. 资料目标是“可查可用”，因此会优先整理成实战速查表，而不只是原始数据堆砌。
